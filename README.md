# Java Calculator

## About
A simple calculator developed using Java with the help of switch-case statements.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input using Scanner

## Technologies Used
- Java
- Scanner Class
- Switch-Case

## How to Run
1. Clone or download this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the program:
   `javac Calculator.java`
4. Run the program:
   `java Calculator`
